# UniAtlas Self-Hosted Deployment Guide

This directory contains configuration files and deployment instructions for hosting **UniAtlas** (`atlas.bogazici.app`) on a self-hosted Docker Swarm cluster via **Dokploy**.

## Infrastructure & Stack Overview

- **App Name**: `uniatlas`
- **Domain**: `atlas.bogazici.app`
- **Container Registry**: `registry.bogazici.app/budok/uniatlas:latest`
- **Orchestration**: Docker Swarm via Dokploy Stacks
- **Reverse Proxy**: Traefik with automated Let's Encrypt TLS certificates

## Deployment Architecture

```
[Internet] --> [Traefik (atlas.bogazici.app)] 
                 |
                 +--> [uniatlas:8000] (FastAPI + Embedded React Frontend + SQLite DB)
```

## Setup Instructions on Dokploy

1. Log into your Dokploy instance (`https://dokploy.bogazici.app`).
2. Create a new **Stack** (or Compose Project) named `uniatlas`.
3. Paste the contents of [`docker-stack.yml`](./docker-stack.yml).
4. In GitHub Repository Secrets, configure:
   - `REGISTRY_USERNAME`: Custom registry username
   - `REGISTRY_PASSWORD`: Custom registry password / token
   - `DOKPLOY_API_KEY`: Dokploy API key
   - `DOKPLOY_URL`: `https://dokploy.bogazici.app`
   - `DOKPLOY_COMPOSE_ID`: Compose ID generated by Dokploy for `uniatlas`
5. Push to `main` branch to trigger the GitHub Actions workflow.
